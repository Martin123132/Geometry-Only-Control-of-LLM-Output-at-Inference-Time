# ManifoldGuard v0.1.7 Release Candidate Notes

Status: release candidate prepared; not tagged or published

Target package: `manifold-guard==0.1.7`

Preparation date: 2026-07-10

## Summary

Version `0.1.7` focuses on reviewing large candidate pools without changing
ManifoldGuard's reference-bounded emit/block safety behavior.

## User-facing changes

- Candidate reports distinguish candidates blocked before ranking, the emitted
  candidate, and safe alternatives.
- Normalized duplicate candidates reuse the first matching safety evaluation
  while remaining visible in audit output.
- JSON, Markdown, and CSV reports expose full-pool totals for submitted, unique,
  duplicate, safe, and blocked candidates.
- `--candidate-filter` narrows report rows to `all`, `safe`, `blocked`,
  `duplicates`, or `unique` candidates.
- `--candidate-order` orders report rows by `input`, `score`, or `selection`.
- Report filtering and ordering preserve the full-pool action, emitted candidate,
  original candidate indices, and safety totals.

## Compatibility and boundaries

- Core operation remains offline-first with `--no-embeddings` or
  `use_embeddings=False`.
- Embedding-backed behavior remains optional through `.[embeddings]`.
- No regulation API signatures were removed or changed incompatibly.
- ManifoldGuard regulates against supplied reference structure; it is not a
  universal fact checker.
