## Release notes

This release adds focused offline usability support for:

- built-in `manifold-check --demo` package smoke tests
- `--why` as a friendly alias for `--explain`
- public demo corpus and CLI quickstart guidance
- Markdown audit output examples for fresh installs
- regression coverage for demo text, JSON summary, Markdown audit output,
  `--fail-on-block`, and demo corpus alignment

No public API signature changes were introduced.
