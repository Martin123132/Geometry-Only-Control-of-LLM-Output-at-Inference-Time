adds a permanent paired performance acceptance gate. Public APIs, complete
frozen-workload candidate records, and the optional embedding boundary remain
unchanged.

## Release boundary

Performance measurements remain scoped to the documented frozen synthetic
workload and recorded development machine. ManifoldGuard regulates candidate
outputs against supplied reference structure; it is not a universal fact
checker or a cross-machine latency guarantee.
